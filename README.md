# Projeto Confeitaria - Módulo de Cadastro (TCC)

Este projeto é um sistema de cadastro de clientes e painel administrativo desenvolvido em PHP Orientado a Objetos com persistência em MySQL.

## 🚀 Como rodar o projeto na sua máquina:

1. **Pré-requisitos:** Ter o XAMPP ou WAMP instalado.
2. **Clonar o projeto:** Baixe os arquivos e coloque-os na pasta `htdocs` do seu XAMPP.
3. **Configurar o Banco de Dados:**
   - Abra o **phpMyAdmin** (localhost/phpmyadmin) ou MySQL Workbench.
   - Crie um banco de dados chamado `confeitaria_tcc`.
   - Importe o arquivo `confeitaria.sql` que está na raiz deste projeto.
4. **Acessar o sistema:**
   - Abra o navegador e digite: `http://localhost/nome-da-sua-pasta/index.php`.
